# 雨课堂视频连续播放助手

为东南大学研究生雨课堂页面提供视频之间的自动切换。目标是以正常速度播放当前课程，播放结束后进入下一条视频，跨章节时跳过作业。

## 安装和使用

1. 在 Edge 或 Chrome 中安装 Tampermonkey，并按扩展提示允许运行用户脚本。
2. 关闭此前的“油猴安装检查”和“目录结构采集”脚本。
3. 在油猴菜单中选择“添加新脚本”，删除默认代码，将根目录 `yuketang-autonext.user.js` 的全部内容粘贴进去，按 Ctrl+S。
4. 刷新已登录的课程视频页。右下角会出现“雨课堂 · 连续播放”面板。
5. 先在左侧打开准备观看的视频。确认面板下拉框与当前视频一致；没有自动识别时，手动选择当前小节。
6. 点击“开始 / 继续”。保持课程页前台，以正常速度播放。视频实际结束后，脚本等待 1.8 秒，再选择目录中的下一条视频。
7. “暂停”和“停止”都会取消后续自动切换并暂停视频。“开始 / 继续”可以重新开启。手动点击目录也会停止自动切换。

也可在装有油猴的 Edge 或 Chrome 中打开[安装链接](https://raw.githubusercontent.com/IridescentLumos/yuketang-autonext/main/yuketang-autonext.user.js)，由油猴安装或更新。

## 没有面板时如何检查

油猴管理面板里的绿色开关表示脚本已启用，不代表它正在当前网页运行。打开课程页上的油猴菜单，应能看到“雨课堂：视频连续播放助手”。

- 先确认版本为 0.1.1 或更高，并刷新课程页。
- 在 Edge 扩展管理页检查 Tampermonkey 的用户脚本权限；有“允许用户脚本”时开启它，否则按扩展提示启用开发者模式。
- 本脚本匹配 `https://seugs.yuketang.cn/*`。如果视频页实际位于其他域名，请提供网址以适配。
- 从平台首页进入课程时，0.1.1 会等待课程路径出现后加载控制面板；平台首页上会显示“已加载”的提示。
- 有面板但不能播放或切换时，点击“自检 / 复制诊断”，将结果发回。诊断只包含页面路径、目录数量、播放器状态和运行记录，不含 Cookie 或媒体地址。

0.1.1 修正了新版视频地址 `/ai-workspace/lms-graph/<课程ID>/video/<视频ID>` 不在旧版匹配范围内、导致脚本没有加载的问题；同时保留旧版 `/pro/lms/` 的课程识别。视频之间路径改变时仍会识别为同一门课程。该版本还增加加载状态和诊断，并将下一节的点击目标改为实际视频标题。

## 功能和范围

- 按目录顺序播放，从当前小节继续，跨章节时跳过作业、考试和其他已识别的非视频单元。
- 以播放器实际结束状态作为切换条件，维持 1.0 倍播放速度。
- 提供开始、暂停、停止、面板收起和运行记录。
- 处理重复结束事件、取消操作、手动切换、播放器变化和加载超时。
- 当前适配域名为 `seugs.yuketang.cn`，目录类名为 `.nav-list`、`.leaf-item`、`.leaf-item-title`、`.leaf-item-tag`，播放器为 `video.xt_video_player`。

## 验证状态

基础控制逻辑及本地浏览器合成课程已验证：顺序播放、跨章节跳过作业、最后一节停止、暂停取消、手动切换停止、未知任务暂停。真实平台的页面结构来自用户采集；尚未在登录后的真实课程中完成端到端验证。

首次使用请观察连续两节，以及一次跨章节切换，确认页面完成度正常更新。平台完成度由原播放器记录；1.8 秒等待并不保证服务器已保存成功。

## 已知限制

- 课程页切到后台会暂停，这是用户已确认的平台行为。此版本需要课程页保持前台；不会绕过页面前台要求。
- 浏览器阻止自动播放时，面板会提示点击视频播放按钮或“开始 / 继续”。
- 如果章节折叠导致目录项目没有加载，请先展开章节。脚本只操作已经载入目录的项目。
- 遇到登录失效、播放器无法加载、未知目录类型或同名目录项时，需要手动确认后继续。
- 页面结构发生变化时可能需要重新适配。作业、考试、测验及完成度确认由用户自行处理。

脚本通过原页面播放器和目录进行操作，不保存登录信息，不发送独立的进度请求。

## 采集页面结构

1. 在 Edge 或 Chrome 中安装并配置 Tampermonkey。
2. 在油猴菜单中选择“添加新脚本”，删除默认代码，将 `tools/inspect-course.user.js` 的全部内容粘贴进去，按 Ctrl+S。
3. 刷新已登录的课程视频页。右下角会出现“目录结构采集”面板。
4. 选择当前的视频小节，点击“生成结果”与“复制结果”。将结果发送给开发者用于页面适配。
5. 采集完成后，在油猴管理面板中关闭采集脚本，再刷新课程页。

工具仅在 `https://seugs.yuketang.cn/pro/lms/` 下运行，只读取目录和播放器结构，不点击课程、不控制播放、不发送网络请求。报告不包含 Cookie、媒体地址、账号信息或讨论区内容。诊断结果留在本地，不应上传到公开仓库。

## 开发检查

安装 Node.js 后运行 `npm test`，无需安装额外依赖。修改 `src/core.cjs` 或 `src/app.js` 后运行 `npm run build`，重新生成根目录安装脚本。

本地浏览器验证：运行 `node tests/fixture-server.cjs`，打开 `http://127.0.0.1:8765/pro/lms/demo/class/studycontent`。该页面使用合成课程及短媒体，不连接真实课程平台。结束后按 Ctrl+C 关闭服务。
